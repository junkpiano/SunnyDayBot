# Data freshness — spec

## Purpose

Tell the reader how current the figures are.

## Behaviour

The header shows when the page was last built, in JST (`Updated 2026-11-22 20:26 JST`).

## Acceptance

- FRESH-1: The header shows when the page was built, as `Updated YYYY-MM-DD HH:MM JST`.

## Not doing

- Per-card timestamps: every card is built in the same run.
