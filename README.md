# SunnyDayBot

Daily market forecast report generated by a Rust pipeline as a static site on GitHub Pages.

## What It Does
- Fetches historical prices for NASDAQ, S&P 500, Nikkei 225, gold and Bitcoin.
- Trains a Prophet model on the most recent window of data.
- Forecasts the next 30 days and classifies the current price as BUY/SELL/HOLD.
- Estimates the next NAV of mutual funds (All-Country, S&P500, SCHD and gold funds) and marks new highs since inception.
- Renders charts and writes the site to `site/`.

## Requirements
- Rust toolchain (stable)
- `pkg-config` and fontconfig headers for the charts (`libfontconfig1-dev` on Debian/Ubuntu)

## Local Run
```bash
cargo run --release
```

Artifacts:
- `site/index.html` (from `src/template.html`)
- `site/*_forecast.png`

## Deploy
The GitHub Actions workflow at `.github/workflows/deploy.yml` runs at 7:00, 13:00 and 19:00 JST and on manual dispatch:
- Builds and runs the Rust forecast. Pull requests also run the tests, and do not deploy.
- Deploys `site/` with `actions/deploy-pages`. In the repository settings, Pages must use "GitHub Actions" as its source.

## Configuration
Adjust these constants in `src/main.rs`:
- `TICKERS` for tracked indices
- `FUNDS` for mutual funds (NAV CSV, tracked ticker)
- `HISTORY_YEARS`, `TRAIN_DAYS`, `FORECAST_DAYS`
- `THRESH` for BUY/SELL thresholds
