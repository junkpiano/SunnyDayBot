# Historical Accuracy & Drawdown Metrics

Each fund card must display transparency and context metrics beneath the primary estimate:

- **All-Time High (ATH) Tracking:** Show the highest NAV recorded since inception, the date it occurred (e.g., High since inception 39,019円 on 2026-08-14), and the current percentage drawdown from that peak (e.g., -8.8%).
- **Model Accuracy / Estimate Error:** Display the rolling average estimation error in both JPY and percentage over a trailing window (e.g., Estimate error: avg 70円 (0.19%) over 12 NAVs), plus the most recent reconciliation (after 11/19: 35,558 vs actual 35,574) to build user trust.
